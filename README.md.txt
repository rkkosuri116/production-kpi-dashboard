# Production KPI Dashboard

## Overview
This project simulates a manufacturing production monitoring system using Python and Power BI.  
The system analyzes production KPIs, downtime events, defect rates, and shift-wise production performance.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Power BI

## Features
- Production KPI calculation
- Defect rate analysis
- Downtime analysis
- Shift-wise production analysis
- Machine-wise production visualization
- CSV data export pipeline
- Power BI dashboard integration

## KPI Metrics
- Total Production
- Total Defects
- Total Downtime
- Defect Rate

## Industrial Relevance
This project demonstrates basic Industry 4.0 and manufacturing analytics concepts including:
- production monitoring
- factory KPI tracking
- manufacturing data analysis
- operational performance visualization
